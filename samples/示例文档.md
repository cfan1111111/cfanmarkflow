## 3. 代码块

```javascript
function greet(name) {
  // 问候函数
  const msg = `Hello, ${name}!`;
  console.log(msg);
  return msg;
}
greet("MarkFlow");
```

```python
def fib(n):
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a
```
